# oh my coffee

Fellow Aiden recipes, tastings, and one-variable-at-a-time revisions in a small personal web UI.

## What is included

- Persistent D1 tables for beans, cups, versioned recipes, and tastings
- Aiden-specific nominal-dose and actual-dose calculations
- Bloom correction, basket range, cup headspace, and iced thermal checks
- Taste/drawdown logging and a conservative next-variable recommendation
- Codex prompt copy and Codex JSON import workflow
- Seed data for the Harfusa example and 315/420/500ml vessels

The starting recipe is deliberately a baseline, not a claim of universal optimum. Record the first brew and calibrate the assumptions—especially grinder calibration, beverage yield, drop temperature, and ice remaining.
